# country-states.json

Every country with its states/regions, used by the client form's Country and State dropdowns.

Source: [countries-states-cities-database](https://github.com/dr5hn/countries-states-cities-database)
by Darshan Gada, licensed under the Open Database License (ODbL) v1.0. Reduced to country and
state names only. India's list is replaced with the app's own state names (`config/ipo.php` maps
them to Patent Offices).
